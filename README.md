# 📩 SMS Spam Classifier

An end-to-end Machine Learning project that classifies SMS messages as **Spam** or **Not Spam (Ham)** using Natural Language Processing (NLP), TF-IDF vectorization, and Multinomial Naive Bayes.

The application provides an interactive web interface built with Streamlit, allowing users to enter text messages and receive instant classification results.

## 📌 Project Overview

SMS spam messages are commonly used to distribute unwanted advertisements, fraudulent offers, phishing links, and misleading information.

This project addresses the problem by developing a machine learning model that automatically classifies SMS messages into two categories:

- **Spam:** Unwanted or potentially suspicious messages.
- **Ham:** Legitimate, non-spam messages.

The system uses text preprocessing and TF-IDF feature extraction to convert messages into numerical representations. A trained Multinomial Naive Bayes classifier then predicts the category of the input message.

The model is integrated into a Streamlit web application and deployed using Streamlit Community Cloud.

## ✨ Features

### 📩 SMS Message Classification

Users can enter an SMS message and receive a prediction from the trained machine learning model.

### 🧹 Text Preprocessing

The application preprocesses messages using the following operations:

- Convert text to lowercase.
- Tokenize the text into individual words.
- Remove punctuation and non-alphanumeric tokens.
- Remove English stopwords.
- Apply stemming using the Porter Stemmer.

### 🔢 TF-IDF Feature Extraction

The fitted TF-IDF vectorizer transforms preprocessed messages into numerical features that can be processed by the trained classifier.

### 🧠 Machine Learning Prediction

The trained Multinomial Naive Bayes model predicts whether an input message is spam or ham.

### 🎨 Interactive Streamlit Interface

The frontend includes:

- A clean white and soft-blue theme.
- An SMS input area with a helpful placeholder.
- A character counter.
- A Check Message button.
- Sample SMS buttons for quick testing.
- Clear and reset functionality.
- Styled spam and not-spam result cards.
- An expandable About section describing the project.

### 🔄 Automatic Result Clearing

The previous prediction disappears when the user starts editing the message, preventing an old result from being confused with a new input.

## 🧠 Machine Learning Approach

This project uses **Multinomial Naive Bayes** for text classification.

The classifier works with numerical text features generated by the TF-IDF vectorizer.

TF-IDF (Term Frequency–Inverse Document Frequency) represents the importance of words in a document relative to a collection of documents.

Multinomial Naive Bayes uses the extracted features to predict the message category.

### Classification Workflow

```text
          SMS Message
               |
               v
       Text Preprocessing
               |
               v
       TF-IDF Vectorization
               |
               v
   Trained Naive Bayes Model
               |
               v
      Classification Result
               |
         +-----+-----+
         |           |
         v           v
        Spam        Ham
```

The trained model and fitted vectorizer are stored in the following files:

- `model.pkl` — saved machine learning classifier.
- `vectorizer.pkl` — saved TF-IDF vectorizer.

These files are loaded by the Streamlit application to make predictions without retraining the model for each message.

## ⚙️ Model Integration

The application uses two saved files to generate predictions:

**`model.pkl`**

Contains the previously trained Multinomial Naive Bayes classifier.

**`vectorizer.pkl`**

Contains the fitted TF-IDF vectorizer used to transform processed SMS messages into numerical features.

During prediction, the application follows this sequence:

1. Accept the user's message.
2. Apply the same text preprocessing approach used during model training.
3. Transform the processed message using the fitted vectorizer.
4. Pass the resulting features to the trained classifier.
5. Display the predicted category.

The model and vectorizer must use compatible preprocessing and feature configurations.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/gishika190905-lab/sms_spam_classifier.git
```

### 2. Navigate to the project directory

```bash
cd sms_spam_classifier
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows:**

```powershell
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
streamlit run sms_spam_classifier.py
```

The application will be available at the local URL displayed in the terminal

**Note:** The saved model and vectorizer files must be present in the project directory. The scikit-learn version should also be compatible with the version used to create the saved model.

## ⚠️ Limitations

- Classification performance depends on the training dataset and the patterns learned by the model.
- Unfamiliar slang, misspellings, abbreviations, and newly emerging spam patterns may affect predictions.
- A message classified as ham is not guaranteed to be safe.
- The system is limited to the categories learned during training.
- The saved model and vectorizer must remain compatible with the application's preprocessing pipeline.
